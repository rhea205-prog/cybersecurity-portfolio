# Failed Login Investigation

## Scenario

A security analyst reviewed Windows Security Event Logs to identify failed login attempts and determine whether suspicious authentication activity had occurred.

---

## Objective

Investigate Windows Security logs using Event Viewer and identify failed login events.

---

## Tools Used

- Windows Event Viewer
- Windows 11

---

## Skills Demonstrated

- Log Analysis
- Event ID Investigation
- Authentication Monitoring
- Security Monitoring

---

## Event ID

4625

---

## Findings

Windows Event Viewer recorded failed login attempts under Event ID 4625.

The logs included:

- Date and time
- Username
- Logon type
- Failure reason
- Source workstation (when available)

---

## Lessons Learned

- Failed login attempts are recorded as Event ID 4625.
- Event Viewer provides valuable authentication information.
- Reviewing failed logins helps identify possible unauthorized access attempts.
