# Splunk Failed Login Investigation

## Scenario

A failed Windows login attempt was intentionally generated to simulate a real-world authentication failure. Splunk Enterprise was configured to collect Windows Security Event Logs, allowing the failed login event to be identified and investigated.

---

## Objective

Use Splunk Enterprise to identify and investigate Windows failed login events (Event ID 4625) and document the findings.

---

## Tools Used

- Splunk Enterprise
- Windows 11
- Windows Event Logs
- Event Viewer
- Splunk Search Processing Language (SPL)

---

## Search Query

```spl
source="WinEventLog:Security" EventCode=4625
```

---

## Investigation Findings

- Event ID: 4625
- Event Type: Failed Login
- Computer Name: Blessed
- Logon Type: 2 (Interactive Logon)
- Authentication Package: Negotiate
- Source IP Address: 127.0.0.1
- Source Process: C:\Windows\System32\svchost.exe
- Audit Result: Audit Failure

---

## Analysis

The failed login events were intentionally generated by entering an incorrect Windows password multiple times. Splunk successfully indexed the Windows Security logs and allowed the authentication failures to be identified using Event ID 4625.

This demonstrates how SIEM platforms help security analysts detect unauthorized access attempts and investigate authentication-related events.
