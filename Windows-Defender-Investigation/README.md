# Windows Defender Investigation

## Scenario

A security analyst reviewed the Windows Security dashboard to verify that endpoint protection was active and the system was protected against malware and other security threats.

---

## Objective

Verify the status of antivirus protection, security updates, and threat detection using Windows Security.

---

## Tools Used

- Windows Security
- McAfee Antivirus
- Windows 11

---

## Skills Demonstrated

- Endpoint Security
- Antivirus Verification
- Security Monitoring
- Windows Administration

---

## Security Features Reviewed

- Virus & Threat Protection
- Current Threat Status
- Protection Settings
- Protection Updates

---

## Findings

The Windows Security dashboard showed that McAfee antivirus was active and protecting the system.

The review confirmed:

- No current threats detected
- Protection settings enabled
- Protection updates current
- No user action required

The endpoint was properly protected and operating normally.

---

## Lessons Learned

- Antivirus software should always remain enabled and updated.
- Windows Security provides a centralized view of endpoint protection.
- Regular security checks help identify protection issues before they become security incidents.
- Endpoint protection is an important layer of a defense-in-depth security strategy.
