# Windows Event Log Analysis

## Scenario

A security analyst reviewed Windows Event Viewer logs to identify system activity and investigate security-related events.

---

## Objective

Analyze Windows Event Logs to understand user logons, system events, and security activity.

---

## Tools Used

- Windows Event Viewer
- Windows 11

---

## Skills Demonstrated

- Log Analysis
- Windows Event Investigation
- Event ID Identification
- Security Monitoring

---

## Event Logs Reviewed

- Security
- System
- Application

---

## Findings

Observed normal Windows activity including user logons, service events, and system startup information.

Common Event IDs reviewed included:

- 4624 – Successful Logon
- 4634 – Logoff
- 6005 – Event Log Service Started
- 6006 – Event Log Service Stopped

---

## Lessons Learned

- Windows Event Viewer contains valuable forensic information.
- Event IDs help identify user and system activity.
- Log analysis is essential for incident investigations.
