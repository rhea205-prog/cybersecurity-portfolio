
# PowerShell System Information Investigation

## Scenario

A security analyst used PowerShell to collect and review system information, running processes, services, and network configuration on a Windows workstation.

---

## Objective

Use PowerShell to gather system information and demonstrate basic Windows administration and security investigation skills.

---

## Tools Used

- Windows PowerShell
- Windows 11

---

## Skills Demonstrated

- PowerShell
- Windows Administration
- System Enumeration
- Process Analysis
- Service Analysis
- Network Configuration

---

## PowerShell Commands Used

```powershell
Get-ComputerInfo

Get-Process

Get-Service

Get-NetIPAddress
```

---

## Findings

PowerShell successfully collected information about the Windows system, including operating system details, active processes, running services, and network configuration.

The investigation identified:

- Operating system information
- Running processes
- Active Windows services
- Network IP configuration

PowerShell provides a fast and efficient way to gather system information for troubleshooting and security investigations.

---

## Lessons Learned

- PowerShell is an essential tool for Windows system administration.
- System information can be gathered quickly using built-in cmdlets.
- Reviewing running processes and services helps identify normal system activity.
- PowerShell is widely used by cybersecurity professionals for investigation and automation.
